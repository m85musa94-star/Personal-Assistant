# مركز القيادة

منظومة عربية لإدارة المهام والجدولة وتتبع الوقت لمدير المكتب ومدير الحسابات ومساعد المدير.

- لوحة قيادة، «يومي»، قائمة مهام بفلاتر وبحث، لوحة كانبان بالسحب والإفلات
- تقويم (ميلادي + هجري) ومواعيد، قوالب دورية (مالية/مكتبية/إدارية) وتكرار تلقائي
- تتبع وقت المهام وتسجيل الدوام، تقارير، تصدير JSON/CSV، تنبيهات المتصفح، يعمل دون اتصال (PWA)

## التشغيل
افتح `index.html` مباشرة، أو: `python3 -m http.server` ثم http://localhost:8000

## النشر على الويب
ادمج الفرع في `main` وفعّل GitHub Pages (Settings ← Pages ← Source: GitHub Actions).
أو اسحب المجلد إلى Cloudflare Pages / Netlify Drop.

## ملاحظة
البيانات تُحفظ داخل المتصفح (localStorage) — صدِّر نسخة احتياطية بانتظام. مواعيد قوالب الضريبة والتأمينات اقتراحية؛ تحقق من المواعيد الرسمية.

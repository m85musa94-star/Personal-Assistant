# مركز القيادة

منظومة عربية لإدارة المهام والجدولة وتتبع الوقت لمدير المكتب ومدير الحسابات ومساعد المدير، بتسجيل دخول حقيقي (بريد + كلمة مرور) ومزامنة على كل الأجهزة.

- **واجهة على طراز أودو:** شبكة تطبيقات، شريط علوي بقوائم كل تطبيق، لوحة تحكم بمسار التنقل والبحث والفلاتر، عروض بطاقات/قائمة، ونماذج بعلامات تبويب وشريط حالة.
- **الشركات:** أضف عدة شركات، ومن مبدّل الشركات في الشريط العلوي تختار شركة أو «كل الشركات» فتتقيّد كل الشاشات بها.
- **الموظفون (تحت كل شركة):** بيانات الموظف، والوثائق (الإقامة، التأمين الطبي، الجواز، العقد، رخصة العمل، رخصة القيادة…) بتواريخ انتهاء وتنبيهات، وسجل الإجازات بالأرصدة.
- **السيارات:** المركبات (لوحة، ماركة، موديل، سائق، عداد، حالة)، وثائقها (استمارة، تأمين، فحص دوري، بطاقة تشغيل…)، وسجلاتها (صيانة، إصلاح، وقود، مخالفات، حوادث) مع التكاليف.
- **التنبيهات:** كل الوثائق المنتهية أو القريبة من الانتهاء (30/60/90/180 يومًا) للموظفين والمركبات، مع شارة في الجرس.
- **المهام والجدولة:** لوحة قيادة، «يومي»، مهام بفلاتر وبحث، كانبان، تقويم (ميلادي + هجري)، قوالب دورية، تتبع وقت، تقارير، تصدير JSON/CSV.
- **اللغة والمظهر:** عربي (RTL) وإنجليزي (LTR) في كل الشاشات، ووضع فاتح وداكن؛ يُحفظان في حساب المستخدم.
- **الأدوار:** مدير النظام (كل شيء)، مسؤول الموظفين والمركبات (التعديل على بياناتهم)، مستخدم عادي (عرض فقط).
- **لا يوجد:** رواتب أو محاسبة، ولا حسابات دخول للموظفين، ولا حضور وانصراف ولا اعتمادات إجازات (الإجازات سجلات يدخلها المسؤول). لا أرقام استحقاق افتراضية للإجازات؛ يدخلها المسؤول.
- **الحسابات:** لا يوجد تسجيل ذاتي. المدير يضيف المستخدمين من «حسابات الدخول»، وكل مستخدم يغيّر كلمته من «حسابي».

## التشغيل المحلي (للمطوّر)
```bash
composer install
cp .env.example .env && php artisan key:generate
touch database/database.sqlite && php artisan migrate
php artisan markaz:set-password you@example.com 'كلمة-مرور-10-أحرف-فأكثر'   # أو افتح /setup في المتصفح
php artisan serve
php artisan test
```

## النشر على Laravel Cloud
1. أنشئ تطبيقًا من هذا المستودع (الفرع الحالي)، المنطقة: الشرق الأوسط.
2. أضف قاعدة **Postgres** واربطها بالتطبيق (تُحقن بيانات الاتصال تلقائيًا).
3. متغيرات البيئة:
   ```
   APP_NAME="مركز القيادة"
   APP_LOCALE=ar
   APP_TIMEZONE=Asia/Riyadh
   SESSION_SECURE_COOKIE=true
   ADMIN_EMAIL=بريدك
   ADMIN_PASSWORD=كلمة مرور قوية (10 أحرف فأكثر)
   ADMIN_NAME=اسمك
   ```
4. أوامر النشر (Deploy commands): `php artisan migrate --force` ثم `php artisan markaz:bootstrap-admin`
   (الثاني ينشئ حساب المدير في أول نشر فقط. لو نسيت كلمة المرور: أضف `ADMIN_RESET=true` وأعد النشر ثم احذفه.)
5. أوامر البناء: `composer install --no-dev --no-interaction --prefer-dist --optimize-autoloader`

## ملاحظات
- أنواع الإجازات تُنشأ بأسمائها فقط دون أي أيام؛ أدخل الاستحقاق السنوي من «الإعدادات ← أنواع الإجازات».
- تجاوز رصيد الإجازة يُنبَّه إليه ولا يمنع التسجيل؛ السجل يعكس الواقع.
- عدد أيام الإجازة يُحتسب بالأيام التقويمية افتراضيًا ويمكن تعديله يدويًا في الطلب.
- إن ظهر خطأ 500 في صفحات جديدة بعد نشر تحديث، تأكد أن أوامر النشر تتضمن `php artisan migrate --force`.
- مهام كل مستخدم تعمل أيضًا دون اتصال وتُزامَن عند عودته؛ الأحدث يفوز عند التعارض بين جهازين.
- مواعيد قوالب الضريبة والتأمينات والزكاة اقتراحية؛ تحقق من المواعيد الرسمية.
